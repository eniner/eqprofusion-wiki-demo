Running MQ

Getting started with MQ; You will need to start macroquest.exe WITH admin rights. If you're using more then one character you should start eqbcserver.exe as well. Once you get all your char(s) loaded into character select screen you should see a MQ box on the same screen. So you know that MQ is loaded. Down below are a list of commands that I use, and have classified them as basic, or as advanced commands.

Notes

  • If you're using EQBCserver.exe your characters will automatically connect to the server.

  • If you're using more then 1 computer then make sure you set your correct IP in MQ2EQBC.ini

MQ2 AutoLogin plugin

In the MQ2AutoLogin.ini add in [Servers] section:

[Servers] PF=[] Enine's ProFusion

and each user account:

[AccountName] Password=Password Server=PF Character=CharName

For more help : https://www.redguides.com/community/resources/mq2autologin.86/
