Setting up your client

Updated from eqprofusion.orgLast updated 2026-10-14

Getting Started - Client (RoF2)

Obtain a copy of EverQuest Rain of Fear 2

- **Nobody here can help you with getting a copy of the RoF2 client**

To create a server login account

- Visit/Create a account on [eqemulator.org](https://www.eqemulator.org/)

After creating your account, if you don't receive your verification email….you will need to request it again.

    - [Request Verification Email Again](https://www.eqemulator.org/forums/register.php?do=requestemail)

Now that your account is verified, you should have an option on the left hand side to “Create Account" nested under LoginServer Accounts.

    - **This account is the one that you use to login to the game.**
  • Go to the root folder of your RoF2 installation. Find the eqhost.txt file and verify that it looks as below:

[LoginServer] Host=login.eqemulator.net:5999 4. Inside the RoF2 folder, find the eqgame.exe file

  • Right Click the file and hover over “Send to” and click “Desktop (create shortcut)"

Find the shortcut on your desktop

- Right click on it and then click Properties

- Add **patchme** to the end of the target field

Profusion Server Files

This is the time that you would need to update a few files. You will need to download and replace the following files. These are also located in the discord channel server-files

Main Everquest folder files

  • spells_us.txt

  • dbstr_us.txt

  • dinput8.dll (Fixes large HP issues with client)

Resource Folder files

  • SkillCaps.txt

  • BaseData.txt

There is a server UI that is suggested to use as well because if you don't some items will show as pearls and not the intended graphic. The UI files are in RoF2 Installation > uifiles > make a folder in that directory that you can reference to change your UI in game

  • Server UI

Troubleshooting Common Issues

If the game is running at super speed or if you cannot create a new character – The cause is due to AMD speed bug. Apply the patch below.

- [AMD Issue Fix](https://discord.com/channels/512858081701527573/512858674583175168/1451210145014218925)

I'm crashing constantly! This can be a number of things but some things that you could try.

- [Download and run this legacy DirectX](https://www.microsoft.com/en-us/download/details.aspx?id=8109) runtime libraries install. It can help with DX crashes.

4GB eqgame.exe patch

    - Run the patch and locate your eqgame.exe and patch it.

    - or [pre-patched eqgame.exe](https://github.com/RekkasGit/E3Next/files/12749369/eqgame.zip) that you can just place in your EQ directory and overwrite the old eqgame.exe




- Use old models instead of the Luclin ones

- Use a toned down GlobalLoad.txt file. [E3N](https://github.com/RekkasGit/E3Next/wiki/5)-Common-issues---FAQ) has one that is toned down but make a backup before you replace it.

If you box more than 1 character, you could setup a EQ directory for the driver and another EQ directory for the bots.

    - Remember, if this route is taken that you must do the server files for both EQ directories.

    - Doing this method can allow you to strip down the bot clients as much as you want and it not interfere with the driver.

Zone Pulls and disconnects

- Take off Yo Momma So Fat Stone

Turn off logging

    - /log off

Turn off some of your filters

    - I have everything set to Hide except for Auctions, Bad Word, Group Chat, Guild Chat, OOC, Shouts and Socials.
